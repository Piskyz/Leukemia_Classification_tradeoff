KEY INSIGHTS FROM ALL MODELS:
----------------------------------------------------------------------------
1. PARAMETER COUNT ISN'T THE KEY: Model 3 had 51M params (best), Model 6 had 370K (worst)
2. BOTTLENECK DESIGN IS CRITICAL: Without compression, autoencoder learns to copy pixels
3. COMPRESSION RATIO MATTERS: Need 50-100x compression for anomaly detection
4. LINEAR LAYERS HELP: Model 3 had linear layers and performed best
5. TOO MUCH CAPACITY WITHOUT COMPRESSION = FAILURE: Model 6 proves this
6. OPTIMAL ARCHITECTURE NEEDS:
   - Strong spatial reduction (multiple pooling layers)
   - Channel reduction before bottleneck
   - Linear layers for abstract feature learning
   - 50-100x total compression ratio
